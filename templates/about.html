🌿 About the Project

This application uses a pretrained Deep Learning model developed with PyTorch to classify flower images into different flower categories.

How It Works

  1. The user uploads a flower image through the web interface.
  2. The image is sent to the Flask backend server.
  3. The image is validated and preprocessed (resize, normalize).
  4. It is converted into a PyTorch tensor and passed to the trained neural network.
  5. The model predicts the flower class and returns probabilities.
  6. The result page displays the predicted class and confidence score.

Technologies Used

  • 🐍 Python
  • 🔥 PyTorch & Torchvision
  • 🌐 Flask
  • 🖼️ Pillow (PIL)
  • 📄 HTML5 & CSS3
  • ⚡ JavaScript
  • 🎨 Jinja2 Templates

Model Details

  • 🧠 Architecture: ResNet18 (fine-tuned)
  • 📦 Input Size: 224 × 224 px
  • 🌸 Output Classes: 5 flower types
  • 📊 Activation: Softmax
  • 🎯 Framework: PyTorch

Supported Flowers

🌼 Daisy 🌻 Dandelion 🌹 Rose 🌻 Sunflower 🌷 Tulip
Note: This project is developed for academic/educational purposes. Predictions are based on the trained model and may not be scientifically accurate in all cases.
